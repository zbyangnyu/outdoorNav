# 任务D：难场景 + 恶劣条件下的路面分割

## 结论（先看这里）
- **B0 CS 抗恶劣条件很强**：暗光、雾、轻中度模糊/噪点/雨几乎不掉分（IoU 0.95~0.98）。明显变差的情况：强过曝 0.76、强运动模糊 0.73、大雨 0.86→0.60（大多是漏认，路没认出来，不是乱认）、强噪点会把非路认成路（误认 0.135）。
- **B0 CS 的真正问题是台阶和草地**：ADE20K 实拍图上，**21% 的台阶像素、32% 的草地/泥土被它认成"路"**。RUGD 野外图上 16% 的草地/泥土被认成路。原因是 Cityscapes 没有"台阶"类，草和土也容易被归到路面。这对导航最危险。
- **ADE 权重**：把台阶/草地认成路的比例很低（台阶 1~2%，草地 3~4%），但台阶也认不全（台阶召回只有 4~14%，主要是"不确定"或者认成别的），而且在实机图上路面本身认得差（IoU 0.80~0.91），雨/噪点下崩溃（B2 ADE 大雨 IoU 0.03）。ADE 分数有"主场优势"（同一个数据集训练的）。→ 不适合直接替换。
- **PIDNet-M（现部署）**：暗光、雨、强噪点下基本全崩（IoU ≤0.13），应尽快换掉。
- **建议**：换 B0 CS，但**要微调**，重点教它"台阶 / 草地泥土 ≠ 路"。

### 类别映射
- 可走路面(1)：RUGD asphalt、concrete；ADE road/route、sidewalk/pavement、path、footpath、runway
- 草地泥土(2)：RUGD dirt、sand、grass、gravel、mulch；ADE grass、earth/ground、field、sand、dirt track、land/soil
- 台阶(3)：ADE stairs/steps、step/stair、stairway/staircase
- 其他(0)：其余；RUGD void、ADE 未标注 = 忽略
- 模型输出映射沿用 `compare.py`（CS：road+sidewalk=路，terrain=草土；ADE 同上表）。

## 3. 微调建议
- 目标：保住 B0 CS 抗光照/天气的能力，同时让它学会"台阶、草地、土路不是路"。
- 数据：①山猫自己的图（校园里台阶、路边草坪、土路、路沿，各几百张，最好含傍晚/逆光/雨天）；②公开数据补充：RUGD（草/土，已验证可下载）、ADE20K 台阶图（训练集里有几百张）。标注可先用大模型+ADE 模型自动出伪标签，再少量人工修正台阶边界。
- 训练时加光照/模糊/噪点/雨的数据增强，防止把现在的抗干扰能力练没。
- 类别建议 4 类：路 / 草土 / 台阶 / 其他。

## 数据下载方式（服务器 `/root/autodl-tmp/seg/taskD/`）
- RUGD 标注：`curl -O http://rugd.vision/data/RUGD_annotations.zip`（61MB，直连快）；图片包 5.6GB 直连很慢，用 `fetch_rugd.py`（remotezip 按需只取选中的图，需 `pip install remotezip`）。
- ADE20K：`https://hf-mirror.com/datasets/1aurent/ADE20K/resolve/main/data/validation-00000-of-00001.parquet`（464MB），`prep_ade.py` 转成 4 类真值（需 pyarrow）。MIT 官方源太慢放弃。
- 脚本：`perturb_eval.py`（步骤1）、`fetch_rugd.py` + `prep_ade.py` + `hard_eval.py`（步骤2）。
